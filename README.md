# 关卡信息

敌人：蟑螂皇帝
我方单位：维吉尔（支援单位），除格里高尔外的罪人均可编队（编队上限11，可同时在场人数6，最大槽位7，初始安瓿3）

行动模式
- 蟑螂皇帝：原版
- 旧G公司部长：在蟑螂皇帝失去所有[防御害虫【蜚蠊】]的下回合，全部使用防御，其余情况按以下循环
    - 技能编号：S1：战时号令，S2：防御命令，S3：攻击命令，防御：表壳硬化
    - A：S2-S3-防御
    - B：S3-防御-S2
    - C：防御-S2-S3
- 维吉尔：原版，第4t进入神备
- 维斯帕：3槽
    - 下简称“蟑螂皇帝失去所有[防御害虫【蜚蠊】]的下回合”为“破盾回合”
    - 蟑螂皇帝1阶段
        - 前两槽使用“牵制”和“二连切”
        - 第三槽使用“该反击了”
            - 若蟑螂皇帝不带有[穿刺标枪]，改为对蟑螂皇帝使用“标枪投掷”
            - 在破盾回合，若蟑螂皇帝带有[穿刺标枪]，改为使用“标枪回收”
    - 蟑螂皇帝2阶段
        - 前两槽使用“冈格尼尔”和“空间斩-闪蜂光剑”
        - 第三槽使用“我来援护”
            - 若蟑螂皇帝带有[穿刺标枪【蜂针】]，改为使用“标枪回收”
            - 若蟑螂皇帝不带有[穿刺标枪【胡蜂针】]，则改为对蟑螂皇帝使用“标枪深埋-就在那里吧。”
            - 在破盾回合，若蟑螂皇帝带有[穿刺标枪【胡蜂针】]，改为使用“标枪回收”
    - 在破盾回合，所有技能的目标均指向蟑螂皇帝
    - 技能目标的选择逻辑同维吉尔，并添加维吉尔同款被动“向导”

# 词条

指标集-衰弱
- 偏废一方α/β：全体我方单位基础技能造成的伤害-50% / 全体敌方单位受到来自[沉沦]、[流血]、[震颤]（包括特殊震颤）、[烧伤]、[破裂]的伤害-50%
- 生命衰竭：全体我方单位（包括支援单位）最大生命-30%，并获得5层[体力恢复降低]
- 罪孽清算：战斗开始时，对全体我方单位施加（最大共鸣数）层该罪孽属性的[伤害弱化]
- 资源匮乏：守备技能无法获得罪孽资源

指标集-险敌
- 撕开包装：蜚蠊皇帝将失去士气低落和恐慌效果
- 苦战：回合开始时，使全体我方单位降低5点理智；支援单位造成的伤害-80%，且维吉尔不会神备
- 烟霾弥漫：回合开始时，对全体单位施加2层[烟气]与3级[烟气]强度；敌方单位每回合首次命中时，额外施加1层[紫色吐息-歇斯底里]
- 反机动：回合开始时，对全体我方单位施加2层[束缚]，对全体敌方单位施加5层[迅捷]

指标集-虫群
- 集群作战：场上出现额外的旧G公司部长（×3，60级，单槽，无需击杀亦可获胜）；我方行动槽数量上限+1
- 难以杀灭（前置词条：集群作战）：旧G公司部长最大生命+50%，每次受到伤害时，最多失去20点生命
- 强化手术（前置词条：集群作战）：旧G公司部长的攻击技能的硬币变为[不可摧毁硬币]，造成的伤害+200%，回合开始时获得5层[强壮]与2层[加算硬币强化]
- 蜚蠊行军α/β（前置词条：集群作战）：蜚蠊皇帝的最大生命+50%；场上每存在一名旧G公司部长，使全体敌方单位在回合开始时获得5层[防御害虫【蜚蠊】]与2层[守护]，并恢复生命上限2%的血量 / 回合开始时，对生命上限最高的一名我方单位施加[狩猎目标]；所有旧G公司部长的攻击技能将指向带有[狩猎目标]的单位，旧G公司部长和蜚蠊皇帝与该单位拼点时拼点威力+5
- 摄取、繁殖α/β（前置词条：集群作战）：旧G公司部长命中时将恢复生命上限5%的血量；旧G公司部长死亡时，将于3t后生成一名旧G公司部长 / 旧G公司部长命中时，使所有罪孽资源-1；蜚蠊皇帝的技能“皇帝的捕食”命中时，使当前持有量最高的罪孽资源-3，并恢复(造成的伤害量)点血量

指标集-变故
- 世界线变动（互斥词条：孤立无援）：安瓿数量+50，维斯帕将取代维吉尔参战
- 孤立无援（互斥词条：世界线变动）：安瓿数量+60，全体我方单位的等级提升至90级，维吉尔将不会出现在战斗中
- 残缺的王国α/β：编队人数上限降低至8 / 可同时在场人数降低至4（不计入支援单位）
